= Payments Service API
:doctype: book
:icons: font

Saga participant. Receives a complete invoice from the orders service, runs a
simulated external transaction, persists the payment and reports the outcome.

Failure simulation is controlled with the fail-mode endpoint and the
`app.payment.fail-mode` / `app.payment.fail-threshold` configuration. An invoice
whose total exceeds the threshold always fails.

== Process an invoice

Receives the complete invoice and executes the (fake) external transaction.
Returns `SUCCESS` or `FAILED` — a failed payment is a normal HTTP response, not
an error.
