= Orders Service API
:doctype: book
:icons: font

Saga orchestrator. Owns the product catalog and the order aggregate
(order + invoice + line items). Drives the saga: create order, add products,
submit (which calls the payments service) and compensate on failure.

== Submit an order

Finalizes the invoice and runs the payment step: status moves to `PROCESSING`
(emits `ORDER_PROCESSING`), then the complete invoice is sent to the payments
service.

* Payment succeeds → `COMPLETED`, invoice `PAID`, emits `ORDER_COMPLETED`.
* Payment fails → compensation: stock restored, invoice `VOID`, status `FAILED`,
  emits `ORDER_FAILED`.
